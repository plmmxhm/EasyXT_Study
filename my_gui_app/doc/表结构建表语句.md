## 表结构建表语句

### 1. 日线数据表 (stock_daily)

```sql
CREATE TABLE IF NOT EXISTS stock_daily (
    stock_code VARCHAR(20) NOT NULL,        -- 股票代码
    symbol_type VARCHAR(10) NOT NULL,       -- 股票类型（stock/etf）
    date DATE NOT NULL,                     -- 交易日期
    period VARCHAR(10) NOT NULL,            -- 周期类型（1d）
    open DOUBLE,                            -- 开盘价
    high DOUBLE,                            -- 最高价
    low DOUBLE,                             -- 最低价
    close DOUBLE,                           -- 收盘价
    volume BIGINT,                          -- 成交量
    amount DOUBLE,                          -- 成交额
    adjust_type VARCHAR(10) DEFAULT 'none', -- 复权类型
    factor DOUBLE DEFAULT 1.0,              -- 复权因子
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, -- 创建时间戳
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, -- 更新时间戳
    PRIMARY KEY (stock_code, date, period, adjust_type)
)
```

## 原始EasyXT项目表结构

### 1. 日线数据表 (stock_daily) - 基础结构

```sql
CREATE TABLE IF NOT EXISTS stock_daily (
    stock_code VARCHAR NOT NULL,
    symbol_type VARCHAR NOT NULL,
    date DATE NOT NULL,
    period VARCHAR NOT NULL,
    open DECIMAL(18, 6),
    high DECIMAL(18, 6),
    low DECIMAL(18, 6),
    close DECIMAL(18, 6),
    volume BIGINT,
    amount DECIMAL(18, 6),
    adjust_type VARCHAR DEFAULT 'none',
    factor DECIMAL(18, 6) DEFAULT 1.0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (stock_code, date, period, adjust_type)
)
```

### 2. 日线数据表 (stock_daily) - 五维复权扩展结构

原始EasyXT项目在启用五维复权后，会通过 `add_adjustment_columns` 方法动态添加以下复权列：

```sql
-- 前复权列
ALTER TABLE stock_daily ADD COLUMN open_front DECIMAL(28, 6);
ALTER TABLE stock_daily ADD COLUMN high_front DECIMAL(28, 6);
ALTER TABLE stock_daily ADD COLUMN low_front DECIMAL(28, 6);
ALTER TABLE stock_daily ADD COLUMN close_front DECIMAL(28, 6);

-- 后复权列
ALTER TABLE stock_daily ADD COLUMN open_back DECIMAL(28, 6);
ALTER TABLE stock_daily ADD COLUMN high_back DECIMAL(28, 6);
ALTER TABLE stock_daily ADD COLUMN low_back DECIMAL(28, 6);
ALTER TABLE stock_daily ADD COLUMN close_back DECIMAL(28, 6);

-- 等比前复权列
ALTER TABLE stock_daily ADD COLUMN open_geometric_front DECIMAL(28, 6);
ALTER TABLE stock_daily ADD COLUMN high_geometric_front DECIMAL(28, 6);
ALTER TABLE stock_daily ADD COLUMN low_geometric_front DECIMAL(28, 6);
ALTER TABLE stock_daily ADD COLUMN close_geometric_front DECIMAL(28, 6);

-- 等比后复权列
ALTER TABLE stock_daily ADD COLUMN open_geometric_back DECIMAL(28, 6);
ALTER TABLE stock_daily ADD COLUMN high_geometric_back DECIMAL(28, 6);
ALTER TABLE stock_daily ADD COLUMN low_geometric_back DECIMAL(28, 6);
ALTER TABLE stock_daily ADD COLUMN close_geometric_back DECIMAL(28, 6);
```

## 原始EasyXT项目与现有项目表结构差异

### 1. 表数量差异

| 项目 | 表数量 | 表名 |
|------|--------|------|
| 原始EasyXT | 4 | stock_daily, stock_1m, stock_5m, stock_tick |
| 现有项目 | 9 | stock_daily, stock_1m, stock_5m, stock_15m, stock_30m, stock_60m, stock_weekly, stock_monthly, stock_tick |

### 2. 字段类型差异

| 字段类型 | 原始EasyXT | 现有项目 |
|---------|------------|----------|
| 价格字段 | DECIMAL(18, 6) | DECIMAL(18, 6) |
| 金额字段 | DECIMAL(18, 6) | DECIMAL(18, 6) |
| 时间戳字段 | TIMESTAMP | TIMESTAMP |
| 复权价格字段 | DECIMAL(28, 6) | DECIMAL(28, 6) |

### 3. 五维复权表结构差异

| 项目 | 复权列处理 | 原始EasyXT | 现有项目 |
|------|------------|------------|----------|
| 复权列添加方式 | 动态添加 | 通过 `add_adjustment_columns` 方法动态添加复权列 | 表结构设计时直接包含复权列 |
| 复权列类型 | 高精度 | DECIMAL(28, 6) | DECIMAL(28, 6) |
| 复权列名称 | 标准命名 | open_front, high_front, low_front, close_front 等 | 与原始项目一致 |
| 复权类型支持 | 五种复权 | 不复权、前复权、后复权、等比前复权、等比后复权 | 与原始项目一致 |

### 4. 字段差异

| 表名 | 差异 | 原始EasyXT | 现有项目 |
|------|------|------------|----------|
| stock_daily | 复权相关字段 | 动态添加复权列 | 只存储原始数据，无复权列 |
| stock_1m | 表数量 | 存在 | 存在 |
| stock_5m | 表数量 | 存在 | 存在 |
| stock_15m | 表数量 | 不存在 | 存在 |
