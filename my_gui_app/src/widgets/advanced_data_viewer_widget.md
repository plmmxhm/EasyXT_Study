# 高级数据查看器使用文档

## 功能说明

高级数据查看器是一个功能强大的股票数据查看工具，支持多种数据周期和数据列的查看与分析。

### 主要功能

1. **多周期数据支持**
   - 日线数据 (1d)
   - 分钟线数据 (1m, 5m, 15m, 30m, 60m)
   - 周线数据 (weekly)
   - 月线数据 (monthly)
   - Tick数据 (tick)

2. **丰富的数据列**
   - 基本价格数据：开盘价、最高价、最低价、收盘价、最新价、前收盘价、前结算
   - 成交数据：成交量、原始成交量、成交额、成交笔数
   - 技术指标：涨跌、涨跌幅、换手率
   - Tick数据特有：买一价、买一量、卖一价、卖一量、成交类型、持仓量、证券状态

3. **复权类型选择**
   - 不复权
   - 前复权
   - 后复权

4. **数据导出**
   - 支持导出为Excel文件
   - 支持导出为CSV文件

5. **股票搜索与筛选**
   - 支持按股票代码搜索
   - 支持按类型筛选（全部、股票、债券）

6. **财务数据查看**
   - 支持查看股票的财务指标
   - 包括：净资产收益率、毛利率、净利率、资产负债率

7. **Tick数据查看**
   - 支持按日期和时间段查看Tick数据
   - 显示详细的成交信息

## 配置说明

### 配置文件路径
高级数据查看器使用与本地数据管理器相同的配置文件：
- 配置文件路径：`my_gui_app/config/data_config.yaml`

### 配置项说明

1. **数据路径配置**
   ```yaml
data_paths:
  root_dir: 'D:/StockData'  # 数据根目录
  raw_data: 'raw'           # 原始数据目录
  factors: 'factors'        # 因子数据目录
  cache: 'cache'            # 缓存目录
  metadata: 'metadata.db'   # 元数据数据库
   ```

2. **数据库配置**
   ```yaml
database:
  dbfile: 'stock_data.ddb'    # 数据库文件名
  batch_size: 100000          # 批量处理大小
  max_connections: 10         # 最大连接数
  overwrite_existing: true     # 是否覆盖现有数据
   ```

3. **存储配置**
   ```yaml
storage:
  format: 'parquet'            # 存储格式
  compression: 'snappy'        # 压缩方式
  partition_by: 'year'         # 分区方式
  temp_file_strategy: 'direct' # 临时文件策略
  temp_dir: 'W:/TEMP'          # 临时目录
   ```

## 使用方法

### 1. 启动应用
- 运行 `my_run_gui.py` 文件启动GUI应用
- 在左侧标签页中选择「高级数据查看器」

### 2. 股票选择
- 在「股票列表」面板中浏览股票列表
- 使用搜索框输入股票代码进行搜索
- 点击「全部」、「股票」、「债券」按钮进行筛选
- 双击股票行加载数据

### 3. 数据类型选择
- 在「控制面板」中选择数据类型：日线、1分钟、5分钟、15分钟、30分钟、60分钟、周线、月线
- 选择复权类型：不复权、前复权、后复权
- 设置日期范围
- 点击「📥 加载数据」按钮加载数据

### 4. 数据查看
- 在「详细数据」标签页中查看加载的数据
- 数据表格支持排序（点击列头）
- 数据表格支持交替行颜色显示
- 涨跌数据会以红涨绿跌的颜色显示

### 5. 财务数据查看
- 切换到「💰 财务数据」标签页
- 点击「💰 加载财务数据」按钮加载财务数据
- 查看净资产收益率、毛利率、净利率、资产负债率等指标

### 6. Tick数据查看
- 切换到「📊 Tick数据」标签页
- 选择日期和时间段
- 点击「📊 加载Tick数据」按钮加载Tick数据
- 查看详细的成交信息

### 7. 数据导出
- 点击「📤 导出Excel」按钮
- 选择导出文件格式（Excel或CSV）
- 选择保存路径
- 点击「保存」按钮完成导出

## 技术实现

### 配置加载
- 使用与本地数据管理器相同的配置加载方法
- 支持从YAML配置文件加载配置
- 提供默认配置作为 fallback

### 数据加载
- 使用多线程加载数据，避免阻塞UI
- 支持从DuckDB数据库读取数据
- 动态构建SQL查询，支持不同数据类型和复权类型

### 数据处理
- 计算额外的技术指标（如均价）
- 处理缺失数据，确保界面显示正常
- 支持数据排序和筛选

### UI设计
- 采用浅色主题风格，符合现有GUI设计
- 响应式布局，适应不同屏幕尺寸
- 提供直观的操作界面

## 注意事项

1. **数据依赖**
   - 高级数据查看器依赖于本地数据管理器下载的数据
   - 请确保已经使用本地数据管理器下载了相关股票的数据

2. **性能考虑**
   - 加载大量Tick数据可能会消耗较多内存和CPU资源
   - 建议在查看Tick数据时选择较短的时间段

3. **错误处理**
   - 如果遇到数据加载失败，请检查数据库连接和数据完整性
   - 错误信息会显示在弹出窗口中，便于排查问题

4. **QMT依赖**
   - 财务数据加载依赖于QMT的xtdata模块
   - 请确保QMT已安装并运行

## 故障排除

### 常见问题

1. **无法加载数据**
   - 检查数据库路径是否正确
   - 检查数据库文件是否存在
   - 检查股票是否有对应的数据

2. **财务数据加载失败**
   - 检查QMT是否已启动
   - 检查xtdata模块是否可用
   - 检查网络连接是否正常

3. **Tick数据加载失败**
   - 检查是否已下载Tick数据
   - 检查选择的日期是否有数据
   - 检查数据库中是否存在stock_tick表

4. **导出失败**
   - 检查文件保存路径是否有写入权限
   - 检查磁盘空间是否充足
   - 检查Excel或CSV文件是否被其他程序占用
